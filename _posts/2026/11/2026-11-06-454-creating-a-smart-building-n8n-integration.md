## Summary
In this stream, Frank returns from his travels in Finland to dive back into building an n8n integration for Schneider Electric's Smart Building BDP platform. He navigates some classic "live coding" hurdles—like forgotten passwords and Docker resets—while discussing the latest AI features in Claude and GitHub Copilot Fusion. The session is a friendly, safe-space brainstorm featuring a new public Kanban board for project tracking, a look at the turn-based indie game *Underkeep*, and plenty of community troubleshooting.
